# Digital Transformation Delivery Analytics Work Sample

## Overview
This project is a SQL and Python analytics work sample designed for a UST-style digital transformation, data analytics, and client delivery environment.

The project demonstrates how I would analyze client delivery performance, SLA health, incident trends, defect backlog, sprint throughput, risk areas, and executive-level recommendations across a portfolio of technology transformation projects.

This project uses synthetic data only. It does not include any confidential UST, client, employee, ticket, project, or operational data.

## Business Context
UST works with organizations on digital transformation, data analytics, automation, cloud, and enterprise technology modernization. In that type of environment, leaders often need a clear view of:

- Which client projects are on track
- Which projects have SLA, backlog, or defect risk
- Where delivery throughput is improving or declining
- Which root causes are affecting delivery performance
- Which clients or workstreams need leadership attention
- What actions can improve delivery quality and business outcomes

## Project Goal
The goal of this work sample is to turn project, incident, sprint, and SLA data into actionable insights for delivery leaders, client stakeholders, and non-technical business audiences.

## Files
- `delivery_portfolio_analytics.py`: Python pipeline for SLA, backlog, throughput, and risk analytics
- `delivery_portfolio_sql_queries.sql`: SQL queries for executive reporting, SLA analysis, defect backlog, and root-cause analysis
- `synthetic_delivery_portfolio_data.csv`: Synthetic UST-style project delivery dataset
- `portfolio_health_summary.csv`: Example client/project health output
- `sla_breach_summary.csv`: Example SLA breach and incident trend output
- `at_risk_delivery_items.csv`: Example leadership escalation output
- `executive_insights_report.md`: Executive-style insight summary
